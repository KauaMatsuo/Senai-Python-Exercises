# SENAI - Python Exercises Portfolio 🐍

Este repositório reúne mais de 56 exercícios, desafios e notas de estudo desenvolvidos durante o curso de Python no **SENAI**. O objetivo deste projeto é consolidar conceitos fundamentais de lógica de programação e estruturas de dados na linguagem Python.

---

## 🛠️ Tecnologias e Ferramentas
* **Python 3.10.11**
* **PyCharm IDE**
* **Git & GitHub**

---

## 📌 Conteúdos Abordados
* **Fundamentos:** Variáveis, operadores aritméticos, entrada/saída de dados e formatação de strings.
* **Estruturas Condicionais:** Tomada de decisão com `if`, `elif`, `else` e tratamento de exceções (`try/except`).
* **Estruturas de Repetição:** Laços de repetição interativos com `for` e `while`.
* **Estruturas de Dados:** Manipulação avançada de Tuplas, Listas e Dicionários.
* **Funções e Modularização:** Criação de funções personalizadas com retorno de valores.

---

## 📂 Organização dos Arquivos
Os scripts estão organizados e nomeados em `snake_case` com numeração sequencial para facilitar a navegação:
* `01_read_user_name.py` até `56_number_words_tuple.py` — Exercícios práticos do curso.
* `d01_mruv_position_calculator.py` — Desafios aplicados.
* `notes_python_fundamentals.py` — Guia de referência dos conceitos básicos.
* `notes_python_advanced_topics.py` — Guia de referência de temas avançados (listas aninhadas, dicionários e funções).
